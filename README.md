# Oleksandr Kashuba — Portfolio

Personal portfolio website for Oleksandr Kashuba, a Systems and Cloud Engineer focused on reliability, automation, and DevOps.

**Live site:** [kapalulz.github.io/PWeb](https://kapalulz.github.io/PWeb/)

## Highlights

- Responsive, multi-page static website
- Professional profile, skills, projects, and contact pages
- Downloadable CV
- Accessible navigation and descriptive metadata
- No application framework or build step required

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Run locally

Clone the repository and serve its root directory with any static web server:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Structure

```text
.
├── index.html        # About page
├── projects.html     # Selected projects
├── contact.html      # Contact details
├── Main.css          # Shared visual system
├── images/           # Images and technology icons
└── files/            # Downloadable assets
```

## Deployment

The production site is published with GitHub Pages from this repository. Changes to the published branch become available after the Pages deployment finishes.
